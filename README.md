# ⚛️ Learning React: Core Fundamentals

This repository serves as my personal lab for mastering React. It contains a collection of mini-projects, coding challenges, and experiments focused on building a deep understanding of the library.

## Learning Roadmap

I am currently following a structured 1-month roadmap to transition from "knowing nothing" to being comfortable with React's modern ecosystem.

### Core Concepts Covered:

- **JSX & Components**: Building reusable UI blocks.
- **Props**: Passing data between parent and child components.
- **State Management**: Using `useState` to make interfaces interactive.
- **Conditional Rendering**: Logic-based UI (e.g., Sold Out badges).
- **Effect Hook**: Handling side effects and API calls.
